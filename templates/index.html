Evaluate an answer sheet

Upload a teacher's answer-key PDF and a student's answer-sheet PDF. The app extracts selectable PDF text and compares answers.

Format your answer key

For best results, use selectable text and put each answer on a separate numbered line/block. The number must match the student's answer number.

Q1: [objective] Paris
Q2: [subjective,5] Photosynthesis is the process by which green plants use sunlight...
Q3: [objective,2] Mitochondria

If you omit the type, the question defaults to subjective and 1 mark. Add [objective] for objective questions and ,5 (or another number) to set maximum marks.

Important limitations

  • This first version supports text-based PDFs, not handwritten or scanned pages.
  • Scanned PDFs need OCR before grading. PDF extraction alone cannot read text inside images.
  • Objective scoring uses exact matching/token overlap; subjective scoring uses semantic similarity from a free Hugging Face sentence-transformer.
  • Similarity is not the same as correctness. Treat the marks as suggestions and review them.
